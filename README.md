# Happy Birthday Muntaha! 🎂✨

An interactive, responsive birthday celebration website dedicated to **Muntaha**.

## Features Included
- **Festive Visuals**: Glowing typography, celebratory night sky aesthetic, smooth glassmorphic cards, and ambient light effects.
- **Interactive Birthday Cake**: 3-tiered cake with blowable candles, smoke effects, and a cake-slicing surprise.
- **Synthesized Music & Sound Effects**: Built-in "Happy Birthday to You" music-box melody and celebration sound effects powered natively by the Web Audio API (zero external audio file dependencies).
- **Floating Balloons with Click-to-Pop**: Rising balloons that pop with confetti bursts and audio effects when clicked.
- **3D Animated Surprise Gift Box**: Unwraps and reveals a heartfelt personalized birthday letter.
- **Wishes & Blessings Board**: Interactive sticky notes with the ability to submit customized wishes saved locally in `localStorage`.
- **Confetti Cannon**: Physics-driven dynamic confetti canvas particles.

## How to Run
Simply double-click `index.html` or open it in any modern web browser (Chrome, Edge, Firefox, Safari).
